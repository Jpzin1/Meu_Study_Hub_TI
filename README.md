# Meu Study Hub TI

Bem-vindo ao meu Study Hub!

Este repositório foi criado como parte da disciplina **Bootcamp I**, do curso de **Ciência da Computação do CEUB**, com o objetivo de organizar minha trajetória acadêmica, projetos, estudos e evolução profissional na área de Tecnologia da Informação.

## Sobre mim

Meu nome é **João Pedro Holanda da Costa**, estudante do 8º semestre de Ciência da Computação.

Atualmente trabalho na **Accenture**, alocado em um projeto do **Banco do Brasil**, atuando principalmente com ambientes de alta plataforma/Mainframe.

Tenho experiência e contato com tecnologias como:

- COBOL
- JCL
- DB2
- TSO
- T-REXX

Também estou ampliando meus conhecimentos em tecnologias de baixa plataforma, incluindo:

- Java
- Maven
- Git
- GitHub

Meu principal interesse profissional permanece na área de alta plataforma e Mainframe, mas também tenho grande interesse pelo desenvolvimento de aplicações modernas e pela integração entre tecnologias legadas e novas arquiteturas.

## Objetivo do Study Hub

O Study Hub será utilizado para centralizar e organizar:

- Anotações acadêmicas
- Resumos
- Exercícios
- Atividades
- Projetos
- Certificados
- Materiais produzidos durante minha graduação

O objetivo é registrar minha evolução acadêmica e construir gradualmente um portfólio que também possa representar minha trajetória profissional.
