# Atividades e Entregas — Bootcamp I

Diretório destinado às atividades e entregas acadêmicas da disciplina Bootcamp I.

## Etapas do Study Hub

### Etapa inicial

Planejamento da identidade profissional, dos interesses de carreira e da estrutura do repositório acadêmico.

### Etapa intermediária

Criação e publicação da versão 1.0 do portfólio no GitHub Pages, com documentação, versionamento e integração com os perfis profissionais.

Principais resultados:

- repositório público organizado por áreas e disciplinas;
- documentação em arquivos README;
- página web responsiva;
- histórico de versões;
- links para GitHub e LinkedIn.
