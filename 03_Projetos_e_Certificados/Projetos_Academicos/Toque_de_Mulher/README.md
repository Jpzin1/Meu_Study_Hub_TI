# Toque de Mulher

Projeto colaborativo de uma plataforma de e-commerce para cosméticos e cuidados pessoais. A organização reúne repositórios de frontend, backend, documentação e apresentação.

## Objetivo

Apoiar a digitalização da operação da Toque de Mulher, com loja virtual, área administrativa e recursos para gestão de produtos e compras.

## Autoria e minha participação

O projeto é desenvolvido em equipe. Minha participação, como João Pedro Holanda da Costa, inclui contribuições em:

- front-end;
- backend;
- banco de dados;
- documentação;
- organização da equipe.

Essas frentes descrevem minha participação no trabalho coletivo, e não autoria exclusiva do sistema. Os demais integrantes também contribuíram para o desenvolvimento e para as entregas do projeto.

## Tecnologias do projeto

- Frontend: React, TypeScript e Vite;
- backend: Python e FastAPI;
- banco de dados: PostgreSQL, com ferramentas de persistência do ecossistema SQLAlchemy;
- documentação: Markdown e repositórios no GitHub.

## Funcionalidades e estado

A documentação pública apresenta catálogo, navegação por produtos, carrinho, checkout, autenticação e área administrativa. Os repositórios também documentam integrações e recursos de gestão. O repositório de documentação registra o MVP em validação; a existência desses recursos não significa que todos os fluxos tenham sido homologados para operação comercial.
