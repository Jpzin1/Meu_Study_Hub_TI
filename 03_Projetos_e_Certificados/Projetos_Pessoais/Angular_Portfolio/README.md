# Portfólio Angular

Portfólio web desenvolvido com Angular e TypeScript, organizado em componentes para apresentar conhecimentos, experiências e projetos.

## Objetivo

Praticar a construção de uma aplicação Angular e apresentar minha trajetória e meus projetos em uma interface web.

## Tecnologias

- Angular e TypeScript;
- HTML e SCSS;
- Angular CLI para desenvolvimento e build.

## Organização da aplicação

O código possui componentes dedicados a cabeçalho, experiências, conhecimentos e projetos, além de uma janela de detalhes dos projetos e da página principal do portfólio.

## Consulta e execução

- [Código e instruções de desenvolvimento](https://github.com/Jpzin1/angular-portfolio)
- [Endereço de demonstração indicado no repositório](https://angular-portfolio-eight-umber.vercel.app)

O README original apresenta comandos do Angular CLI, incluindo `ng serve` e `ng build`. Consulte também o `package.json` para as dependências e os scripts disponíveis. O código é mantido no repositório original.

## Relação com minha formação

O projeto reúne prática de Angular, TypeScript, estilização com SCSS e organização de uma apresentação profissional na web.
