# Projeto Netflix

Projeto de estudo de uma aplicação web inspirada na apresentação de um catálogo de filmes, desenvolvido com Python, Django e templates HTML.

## Objetivo

Praticar a relação entre modelos de dados, páginas e navegação em uma aplicação Django.

## Tecnologias e estrutura

- Python e Django;
- templates HTML;
- modelos Filme e Episodio;
- estrutura de migrações e arquivo de banco SQLite no repositório.

## Funcionalidades identificadas no código

- Página inicial e listagem de filmes;
- página de detalhes de um filme;
- organização por categorias;
- contador de visualizações ao acessar os detalhes;
- indicação de até cinco filmes da mesma categoria;
- modelo de episódios associado aos filmes, com campo para endereço do vídeo.

## Escopo

Trata-se de um projeto de aprendizagem. A estrutura consultada não comprova uma plataforma comercial de streaming nem uma reprodução completa dos serviços da Netflix. Não há README com um procedimento de instalação no repositório original no momento desta documentação.
