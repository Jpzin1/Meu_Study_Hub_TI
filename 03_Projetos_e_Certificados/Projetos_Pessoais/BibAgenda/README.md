# BibAgenda

Interface de um sistema de biblioteca desenvolvida com React e TypeScript a partir do design BibAgenda no Figma.

## Objetivo

Praticar desenvolvimento de interfaces, organização por componentes e navegação em uma aplicação web voltada ao contexto de bibliotecas.

## Tecnologias

- React e TypeScript;
- CSS e HTML;
- componentes separados por layout e páginas.

## Funcionalidades documentadas

- Menu lateral para navegação entre seções;
- cabeçalho com título da seção;
- tela principal da biblioteca com layout responsivo;
- organização de componentes como Header, Sidebar e Layout.

## Estado do projeto

O README do repositório original descreve a interface implementada e lista como próximos passos a ampliação das páginas, persistência no backend, autenticação e testes. Essas etapas não são apresentadas aqui como funcionalidades concluídas.
